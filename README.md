# Flask Hello World 一頁式網站

這是一個基於 Python Flask 框架所建立的 Hello World 一頁式網站範例。

## 專案結構

```
practice0929/
├── app.py                # Flask 主程式
├── requirements.txt      # Python 相依套件清單
├── README.md             # 專案說明文件
└── templates/
    └── index.html        # 一頁式網頁前端範本 (HTML/CSS/JS)
```

## 啟動方式

1. 開啟終端機（PowerShell 或 Command Prompt），切換至本專案目錄：
   ```bash
   cd "c:\Users\lo297\Desktop\桌布\AI與數據分析課程\practice0929"
   ```

2. 執行 Python 程式啟動伺服器：
   ```bash
   python app.py
   ```

3. 開啟瀏覽器並造訪：
   [http://127.0.0.1:5000](http://127.0.0.1:5000)
